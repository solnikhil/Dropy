## Findings resolved

- Derive source geometry from each captured sample, and refuse unknown/cropped geometry. A completed stream update cannot relabel an older frame, including proportional resizes with identical output dimensions.
- Publish input mappings only after drawable presentation. Keep the latest confirmed mapping during animation, while revoking mappings after source/viewport changes.
- Separate drawable misses from final frame outcomes; concurrent presentation/drop callbacks can finalize a frame only once.
- Apply capture-rate hysteresis: 30 unchanged frames enter idle; two consecutive changed frames resume full rate. Every changed frame is forwarded immediately. This prevents reconfiguration artifacts from repeatedly toggling 10/60 fps.
- Bound Accessibility traversal and scope preparation to process launch identity.
- Acquire the kernel device-session lock before builds or preference backup publication. Restore preferences before releasing ownership. Failed or skipped requested checks return failure.
